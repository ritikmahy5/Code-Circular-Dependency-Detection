KEY FEATURES:

✅ Persistent Database: 42,664 entries (42,660 code chunks + 4 patterns)
✅ Local LLM: Ollama CodeLlama 13B (no external APIs)
✅ Clickable Citations: GitHub URLs to source files and patterns
✅ RAG Architecture: Dual knowledge base for context-aware explanations
✅ Performance: <1ms graph building, <0.25ms cycle detection, <5ms RAG retrieval
✅ Accuracy: 100% cycle detection completeness (Tarjan's SCC algorithm)

═══════════════════════════════════════════════════════════════════════════════

DATA FLOW:

1. User uploads code → Frontend
2. Frontend → AST Parser → Extract imports
3. Parser → Chunker → Create 14.8 chunks/file
4. Chunks → Stored in persistent database (42,660 entries)
5. Imports → Graph Builder → NetworkX graph
6. Graph → Tarjan's SCC → Detect all cycles (100% completeness)
7. Cycles → Severity Scorer → Classify by impact
8. Cycles → RAG → Retrieve similar code + patterns
9. RAG Context → Ollama LLM → Generate explanations
10. LLM Response → Frontend → Display with clickable citations

═══════════════════════════════════════════════════════════════════════════════

TECHNOLOGIES:

• Frontend: Streamlit 1.28+
• Graph: NetworkX 3.0+ (Tarjan's SCC algorithm)
• Embeddings: sentence-transformers 5.1.2 (all-MiniLM-L6-v2)
• Vector Store: FAISS-CPU 1.13.1
• LLM: Ollama (CodeLlama 13B local)
• Visualization: Pyvis 0.3.2
• Language: Python 3.11+
• Storage: Pickle (code chunks), JSON (patterns)
